# CareerTwin OS — threat model (lane E, batch CT-2026-11-10-B01)

Scope: the offline, synthetic, single-user system being built in lanes A–D, plus the repository and CI
that hold it. The repository is **public**. Every test here uses fictional data; no test reaches the network.

Each threat lists what lane E tests, where the test is, what was observed on real lane code at the
pinned SHAs in the batch report, and what remains. "Lane-owned" means only that lane can fix it.

## Not covered (explicitly)
* Authentication and API auth: there is no multi-user server in this batch (A's HTTP API binds to loopback only).
* Supply chain of npm/pip dependencies: versions are pinned by lanes; no SBOM or signature checks were run.
* Browser-level XSS in lane D: blocked until D renders pipeline artifacts (`ui.e2e` stage).
* Reviews by lane E are same-provider reviews and do not count as independent external validation.
