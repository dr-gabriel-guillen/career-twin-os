# ADR-0001 — Synthetic-first parallel development

**Status:** ACCEPTED for bootstrap only; owner approvals on production policy remain open.

## Decisions
- Permanent IDs CAREER-TWIN-A/B/C/D/E. One owned branch per session.
- Main contains frozen v0.1 schemas and generic synthetic reference engine. Schema changes require RFC with consumer acknowledgment.
- Collaboration via coordinator Issue #1, per-lane Issues #2–#6, PR review comments; no manual file-passing through owner.
- Agent E tests integration using exact pinned branch SHAs, separate from automated merge.
- Personal-data imports, LinkedIn OAuth, external sends and deployments disabled until owner approval. Current repository visibility PUBLIC must be corrected before storing any personal data.

## Alternatives rejected
- Five agents editing main directly (high collision risk).
- Long chat messages as sole handoff (not durable).
- Scraping LinkedIn or unapproved automation (provider and privacy risk).
- Claiming PCA distance measures hiring success (invalid inference).
- Declaring an A/B variant better without randomized design, sufficient outcomes and honest uncertainty.

## Open decisions
- Change repository visibility to PRIVATE.
- Approve actual job sources, hosting, personal-data controls, model budget and privacy-retention defaults.
- Approve any future PR merges and real deployment.
